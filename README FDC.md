# Notas de instalação BLU

Os passos de instalação e operação estão consolidados nos guias partilhados:

- [README](README.md): requisitos, componentes e comandos principais.
- [Onboarding](docs/ONBOARDING.md): preparação de um novo SageMaker Code Editor.
- [Validação num segundo workspace](docs/SECOND_WORKSPACE_VALIDATION.md): ensaio
  acompanhado, incluindo instalação do Node e configuração dos buckets.
- [Operações](docs/OPERATIONS.md): arranque, recuperação, backups e restauro.

Usar a URL real do próprio workspace. Não copiar URLs privadas, credenciais ou
estado operacional de outra instalação. O agente é executado pelo portal, sem
uma porta HTTP própria; as interfaces atuais são definidas em
`config/workspace_interfaces.json`.
